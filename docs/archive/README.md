so nothing is lost, and because some code comments still cite them by name. **Nothing here is
current.** For what we are building see `docs/NORTH-STAR.md`; for what works see `STATE.md`; for the
plan see `ROADMAP.md`; for the rules see `AGENTS.md`.

| `sdlc.md` | The task-by-task ledger (tasks 1–60). `git log` is the history now |
| `dev-workflow.md` | The pre-v2 process rules. Still-true rules moved to AGENTS |
| `STATE-until-2026-09-25.md` | The long STATE file before the restructure |
