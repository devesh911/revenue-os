The migrations in this folder are the schema. A change is a new migration written for that change, numbered after the last one here (`NNN_name.sql`, run in file order), with each new table's `org_id`, row-level security policies and a cross-tenant denial test in the same PR (AGENTS.md hard rail 3). Migrations are append-only: never edit, rename or delete one already on main, and never reuse a number; `rules-from-main` refuses a PR that does (`scripts/done-gate/migrations.ts`, AGENTS.md hard rail 4). `docs/db-design.md` is reference for intent only: never copy its DDL, which later migrations have changed.
